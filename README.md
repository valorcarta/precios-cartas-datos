# Precios de cartas coleccionables (datos abiertos)

Volcado diario de precios de mercado de cartas Pokémon, generado desde **ValorCarta**.

- **`precios.json`** — id, nombre, set y precio de referencia en EUR de cada carta con datos.
- Fuente del precio: Cardmarket, vía la API pública de TCGdex.
- Actualización: diaria.
- Licencia: CC BY 4.0 — puedes usarlo citando la fuente.

## Para qué sirve

Comparar series, montar gráficas, entrenar modelos o comprobar si una carta está cara **hoy**.

## Dónde verlo con contexto

Cada carta tiene su ficha con histórico, media de 30 días y mínimo en:

**https://valorcarta.github.io**

## Aviso

Los precios son de referencia de mercado y no distinguen estado de conservación. No son una tasación.
